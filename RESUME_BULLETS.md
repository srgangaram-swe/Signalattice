# Resume Bullets

- Built a production-style quant research data platform in Python covering market data
  ingestion, validation, Parquet storage, feature engineering, ML modeling, vectorized
  backtesting, risk analytics, experiment tracking, reporting, tests, CI, Docker, and docs.
- Implemented leakage-aware walk-forward ML for cross-sectional return-direction signals,
  including out-of-sample predictions, feature importance, classification metrics, and
  transaction-cost-aware strategy evaluation.
- Engineered factor pipelines for returns, rolling volatility, Sharpe, RSI, MACD,
  Bollinger bands, momentum, mean reversion, volume, beta, drawdown, and cross-sectional
  ranking features.
- Developed a configurable long-only/long-short backtester with position sizing, position
  caps, slippage, transaction costs, turnover, monthly returns, benchmark comparison, and
  risk statistics.
- Added reproducible research infrastructure with typed YAML configs, deterministic seeds,
  dataset hashing, SQLite/JSON/MLflow-compatible experiment tracking, generated reports,
  Make targets, Docker, pre-commit, and GitHub Actions CI.
