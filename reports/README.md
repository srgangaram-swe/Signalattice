# Reports

Generated reports and figures are written here. Most generated artifacts are ignored by
Git, but `reports/example/` is committed as reproducible synthetic engineering evidence.
It is not evidence of live-market profitability.

Regenerate the sample output:

```bash
bash scripts/run_example_pipeline.sh configs/synthetic.yaml
```

The report joins forecast calibration and stability with cost, delay, capacity-proxy,
latency, exposure, and risk diagnostics. Interpret the source label and explicit readiness
verdict before any headline metric. See the
[validation protocol](../docs/validation_protocol.md).
